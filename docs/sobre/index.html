Como funciona

O Comex Stat, sem precisar saber código NCM

Os dados oficiais de comércio exterior do Brasil são públicos e gratuitos, mas difíceis de consultar. O Comex em Números busca cada atualização mensal do MDIC e transforma em páginas prontas, com nomes que as pessoas procuram.

Fonte e método

  • Fonte: API do Comex Stat, Secex/MDIC. Valores em US$ FOB.
  • Atualização automática no início de cada mês, quando o MDIC publica o mês anterior.
  • Variações sempre contra o mesmo mês do ano anterior.
  • Produtos na classificação SH4 (posição do Sistema Harmonizado). Os nomes curtos são nossos; o nome oficial aparece em cada página.
  • Estado: UF de origem do produto exportado e de destino do importado.
